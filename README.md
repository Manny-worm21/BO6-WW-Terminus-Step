# BO6-WW-Terminus-Step
This tool helps with the Easter Egg (Main Story Quest) step on Terminus in Black Ops 6 Zombies.

To use the program, do "make run" to start the program.

Currently, it needs three numbers x, y, and z after being deciphered from the white board using the sticky notes in game.

After inputting the numbers, it will output the numbers needed to input into the game to proceed to the next step in the Easter Egg.
